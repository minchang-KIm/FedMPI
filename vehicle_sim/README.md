# 차량 연합학습 장애 시뮬레이터

차량 업데이트가 늦거나 오지 않는 34개 유스케이스(서버가 받은 모습 기준 8개 패턴)를 **한 맵에서 실제 FL 학습과 함께** 보여 주는 화면.
SASAFL 원본 파일(`methods/SASAFL/*`)은 수정하지 않고, `fl/sim_sasafl.py`의 서브클래스로 끼워 넣는다.

## 실행

```bash
# 이 폴더(~/Mando/FedMPI-sim, 브랜치 vehicle-fl-sim)에서, FL conda 환경의 python으로
/home/wise-175/anaconda3/envs/FL/bin/python vehicle_sim/serve.py --port 8765
# 브라우저: http://localhost:8765  (원격이면 VS Code 포트 포워딩으로 8765)
```

**▶ 시작**을 누르면 주행 시뮬레이터(world)와 FL(torchrun, 서버 1 + 차량 K)이 함께 뜬다. 3D 맵은 three.js를 인터넷에서 받는다.

## 학습 방식 (같은 하네스, 기능만 켜고 끔 → ablation)

| 방식 | 적응형 quota | staleness 감쇄 | 학습 중 교체·epoch 축소 | quota |
|---|---|---|---|---|
| SASAFL (현재 코드 + optimizer 수정) | O | O | O | C·K부터 |
| SASAFL 원저자 코드 | X | O | O | C·K |
| BSA (SemiAsync) | X | O | X | C·K |
| FedAsync | X | O | X | 1 |
| 동기식 | X | X | X | K |

시드가 같으면 데이터 분할·주행·차량별 무작위 사건이 같게 시작한다 (학습 시간에 따른 순서 차이는 남는다).

## 패턴을 만드는 방법

| 패턴 | 맵·설정 | 구현 / SASAFL이 보는 모습 |
|---|---|---|
| 1 값을 전달받지 못함 | 계산 중단, OTA, 학습 중 방전, 긴급제동 선점, 시동 꺼짐 | 학습 중단, 보내지 않음. **프로세스는 살려 두고 수신은 계속**(원본은 한 대라도 수신을 멈추면 서버 `dist.send`가 막힌다) |
| 2 전송 중 끊김 | 범위 이탈·핸드오버, 도플러, 패킷 오류, 권역 경계, 터널, 전송 중 방전 | 전송 시간을 n등분해 기다리며 연결 확인, 끊기면 보내지 않음. 실제 `dist.send`는 원본처럼 한 번 → 조각 개념이 없어 서버에선 패턴 1처럼 보인다 |
| 3 해당 라운드 미참여 | 에너지 기준, 새 데이터 없음(충전 중·정비 대기), Wi-Fi 조건 | 학습을 시작하지 않고, 조건이 풀리면 **마지막으로 받은 최신 글로벌 모델로 복귀** |
| 4 늦게 도착 | 구형 EV, 기지국 혼잡, 재전송, 대역폭·강우, 긴급제동 연산 점유, 데이터 양, TDMA, 새 모델 수신 실패 | 지연 / 이전 버전으로 학습 → staleness |
| 5 모아서 한꺼번에 | 보관 후 전송 + 터널·음영·셀 가장자리, 서버 장애 | 보관했다가 연속 `dist.send`. 원본 서버는 차량당 버퍼 1칸이라 덮어쓰고 비중을 두 번 나눈다 |
| 6 오류 값 지속 전송 | 업데이트 증폭, 센서 고장 라벨, 학습률 | 매 업데이트마다 오염된 값 전송 (너무 세면 loss NaN → 서버 `int(NaN)` 종료) |
| 7 빠른 클라이언트 편중 | 신형/구형, 통신 품질, 운행 시간대 주기 | 최근 W라운드 참여 비중을 감시해 기준 배수를 넘으면 기록 |
| 8 서버·글로벌 모델 문제 | 서버 장애 버튼, quota > 보낼 수 있는 차량, 새 모델 연속 거부 | 일시 중단 후 복구(차량은 보관), 무한 대기 감지, lag ≥ τ 강제 갱신 기록 |

## 구조

```
vehicle_sim/
  maps/default.json   맵(도로·셀·구역·장소·신호·횡단보도·경로). 같은 형식의 JSON을 화면에서 올릴 수 있다
  simcore/common.py   패턴·유스케이스·학습 방식·차량 종류·설정 기본값·파일 입출력
  simcore/world.py    주행(2차선·차간 거리·신호·보행자·긴급제동)·통신 계산 → world.json, world_state.json, world_hist.jsonl
  fl/fl_entry.py      torchrun 진입점: 시드 고정·Dirichlet 분할·시뮬레이션 클래스 끼우기 → 원본 Start.py 실행
  fl/sim_sasafl.py    SASAFL 서브클래스: 원본 로직 + 장애 주입 + 방식 전환 + 체크포인트 + 기록
  serve.py            HTTP 서버(표준 라이브러리) + 실행·저장·불러오기·로그
  web/                index.html · app.js(three.js) · style.css
  runs/<시각>/        config, world*, server.json, client_<id>.json, events.jsonl, checkpoint.pt, fl.log  (git 제외)
  saves/<이름_시각>/  저장한 상태 (git 제외)
```

## 원본과 다르게 둔 것
1. busy-wait 두 곳에 짧은 sleep (CPU 절약, 동작 동일)
2. **복귀 허용**(전체 설정): 원본은 한 번 빠진 차량이 다시 선택되지 않는다. 끄면 원본처럼 영구 제외
3. 학습 중 글로벌 모델 교체 뒤 optimizer를 다시 만든다 (main `8f430a7`의 버그 수정과 같음)

## 주의
- 실제 학습을 하므로 CPU를 쓴다 (차량 8대 ≈ 프로세스 9개, 1스레드씩). 같은 노드에서 다른 실험이 돌면 그 실험이 느려진다.
- 시간·거리·속도는 실제 단위(1배). 메모리는 실행 시간에 비례해 늘지 않도록 기록·화면 목록에 상한을 두었다 (실행 기록 파일은 디스크에 쌓인다).
