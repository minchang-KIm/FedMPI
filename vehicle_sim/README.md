# 차량 연합학습 장애 시뮬레이터

차량 업데이트가 늦거나 오지 않는 34개 유스케이스(서버가 받은 모습 기준 8개 패턴)를 **실제 크기의 3D 도시에서 실제 FL 학습과 함께** 보여 주는 화면.
SASAFL 원본 파일(`methods/SASAFL/*`)은 수정하지 않고, `fl/sim_sasafl.py`의 서브클래스로 끼워 넣는다.

## 실행

```bash
# 이 폴더(~/Mando/FedMPI-sim, 브랜치 vehicle-fl-sim)에서, FL conda 환경의 python으로
/home/wise-175/anaconda3/envs/FL/bin/python vehicle_sim/serve.py --port 8765 --host 0.0.0.0 --code 123456
# 브라우저: http://<서버 IP>:8765 (접속 코드 입력) · 혼자 쓰면 --host·--code 없이 http://localhost:8765
```

**▶ 시작**을 누르면 주행 시뮬레이터(world)와 FL(torchrun, 서버 1 + 차량 K)이 함께 뜬다. 3D 맵은 three.js를 인터넷에서 받는다.
34개를 한 번에 보려면 '전체 설정 → 34개 전부 보이기' 후 ▶ 시작, 몇 분 뒤 '서버 장애' 버튼(8-1·5-3).

## 맵 7종 (`maps/make_maps.py`로 생성)

| 맵 | 크기 | 특징 |
|---|---|---|

| `port` 항만·산업단지 | 2.4 × 1.6 km | 지하차도, 컨테이너 야적장(음영), 해무(강우), 항만 게이트 혼잡 |
| `newtown` 신도시 순환 | 2.2 × 1.6 km | 외곽 순환대로·내부 순환로·방사형 도로, 업무지구 빌딩 숲, 학교·공원 |

모든 맵은 34개 유스케이스를 일으킬 조건을 갖춘다. 생성할 때 `mapgeo.map_coverage`(경로 위에 터널·음영·셀 가장자리·권역 경계·고속 구간·
충전소·서비스센터·집/직장 정차·Wi-Fi·강우·횡단보도가 있는지)와 `mapgeo.map_problems`(경로가 도로 위에 있는지, 정차 지점에 장소가 있는지,
3갈래 이상 교차로에 신호가 있는지)를 검사하고, 하나라도 빠지면 저장하지 않는다. 화면 '저장·맵' 탭에 맵별 34/34와 유스케이스별 위치가 나온다.
같은 형식의 JSON 맵을 올려도 같은 검사를 한다. 건물·나무·주차장 칸은 맵에서 자동 배치(`mapgeo.map_layout`, 맵 이름으로 시드 고정).
3갈래 이상 교차로의 신호는 `auto_signals`가 자동으로 단다. 큰 곡선 도로·서킷은 `arc()`로 원호를 마디로 나눠 그리며, 마디가 짧은 완만한 굽이는 실제 반경(마디 길이 / 꺾인 각)으로 감속한다.
경로마다 `always`(상시 운행)·`label`(이름표)·`accel`·`brake`·`a_lat`(가속·감속·횡가속 한계)를 줄 수 있다 (레이싱 카 7·9·12 m/s²).

## 배경 차량 (`world.npc_cars`, 기본 16대)

학습에는 참여하지 않고 길만 채우는 차량. FL 차량과 똑같이 강체·신호·보행자를 지키며 맵의 `npc_routes`(없으면 모든 경로)를 돈다.
바닥 링·이름표가 없고, 사건 기록에도 남지 않는다. 넓은 맵을 켜 두고 볼 때 도로가 살아 있게 한다.

## 차종 (외형)

연산 성능은 신형/구형 두 종류뿐이지만 외형은 vid마다 정해진 차종·색으로 다양하게 나온다 (상표는 넣지 않았다).

| 신형 EV | 구형 EV |
|---|---|
| 고급 세단 (E클래스 풍: 긴 보닛·크롬 그릴·가는 LED) | 경형 SUV (캐스퍼 풍: 짧고 높은 차체·둥근 등·투톤 지붕·루프랙) |
| 고성능 세단 (아반떼 N 풍: 퍼포먼스 블루·빨간 립/스커트·리어 윙·쌍 배기구) | 승합 밴 (스타렉스 풍: 짧은 코·긴 측면 유리·슬라이딩 도어) |
| 전기 해치백 (픽셀 라이트 띠) · 전기 SUV | 1톤 트럭 · 중형 세단 · 각진 SUV |

택시 경로는 주황 택시(지붕 표시등), 버스·셔틀 경로는 승합 밴, 서킷의 레이스 경로는 레이싱 카로 그린다.
연합학습 상태는 차체 색이 아니라 **바닥 링·지붕 표시등·이름표 색**으로 보인다 (링이 없는 차 = 배경 차량). 브라우저 콘솔 `__sim.showroom(x, z)`로 모든 차종을 한 줄로 세워 볼 수 있다.

## 하루 시계 (7-3 운행 시간대 편중)

`world.day_minutes`(기본 30분 = 24시간), `world.start_hour`(기본 06:48). 화면 위쪽에 시각·일차·시간대(야간·출근·주간·퇴근·저녁), 하늘·해·조명·창문 불빛이 시각을 따른다.

| 차량 | 하루 |
|---|---|
| 통근 (commute) | 집에서 밤샘 주차 → 07:00–08:30 출근 → 직장 주차(시동 꺼짐) → 17:00–18:30 퇴근 → 귀가 |
| 택시 (city) | 주간조 06–24시 / 야간조 18–10시. 근무가 끝나면 차고지 주차, 가끔 휴식. 운행이 길어 학습 데이터 2배(4-6) |
| 주민 (resident) | 08–21시에 집에 들렀다 나가기를 반복, 밤에는 집 |
| 통과 (visitor) | 시간대별 유입(출퇴근 2.2배, 밤 0.15배) |

집에 주차하면 완속 충전, 충전소는 급속 충전. 보행자는 시간대별 빈도(학교 앞은 등하교 시간에 많음).
서버는 시간대별로 어떤 차량 종류의 값이 집계됐는지 기록하고(화면 '시간대별 참여'), 최근 W라운드 집계 구성이 차량 구성과 다르면 7-3을 기록한다.

## 주행 (강체: 차량끼리 겹치지 않음)

- 차량은 길이 4.6 m·폭 1.9 m 직사각형. 2차선 도로에서 진행 방향 오른쪽 차로 중심선을 따라가며, 모서리는 반경 9 m 곡선(곡선 구간 감속).
- 앞 경로를 1 m 간격으로 훑어 다른 차(앞차·교차로를 지나는 차, 방향 무관)를 찾아 그 앞에서 멈출 수 있는 속도로 줄인다.
- 매 0.1초 이동 후 차량 직사각형끼리 분리축 검사(SAT). 겹치게 되는 이동은 하지 않는다.
- 신호 교차로는 진입 예약: 다른 방향에서 들어온 차가 안에 있거나 출구가 막혀 있으면 정지선에서 기다린다 (교차로 안 교착 방지).
- 정차는 도로 밖 주차장 칸으로 들어가고, 차로가 비어 있을 때만 다시 합류한다.
- 검사: 4개 맵 × 차량 16대 × 3일(실제 90분)에서 겹침 0회, 가장 오래 선 시간 26초(빨간불).

## 여러 사람이 함께 쓰기

```bash
FL python vehicle_sim/serve.py --port 8765 --host 0.0.0.0 --code 123456
```

- 같은 네트워크의 다른 컴퓨터에서 `http://<서버 IP>:8765` 접속 → 접속 코드 입력(한 번 넣으면 30일 기억) → 이름 입력.
- 시뮬레이션은 하나를 모두가 같이 본다. 각자 다른 차량을 골라 동시에 운전할 수 있고, 한 차량은 한 사람만 운전한다(남이 운전 중인 차는 버튼이 잠김).
- 머리글에 접속자 수(마우스를 올리면 누가 어느 차를 보는지·운전하는지), 차량 이름표·차량 칩에 🕹운전자 이름.
- 설정(학습 파라미터 포함)·시작·정지는 누구나 바꿀 수 있고, 바뀐 값은 모든 화면의 폼에 반영되며 "이름: 설정 변경 fl.lr=0.02"처럼 사건 기록에 남는다.
- 서버 IP가 공인 IP면 네트워크 밖에서도 보일 수 있으니 `--code`를 꼭 쓴다.

## 길을 걷는 사람

- `world.walkers`명(기본 40)이 도로 양쪽 보도(고속도로 제외)와 공원을 걷는다. 보도 끝에서는 근처 다른 보도로 길을 건너고, `world.jaywalk_per_min`(1인당 분당) 확률로 무단횡단한다. 시간대마다 밖에 나온 사람 수가 다르다.
- 자동 주행 차는 차로 위 사람 앞에서 멈춘다(급하면 긴급제동 → 4-5·1-4).
- 차와 부딪히면 차 속도·방향대로 날아간다(포물선, 회전, 땅에 튕김, 미끄러짐). 쓰러졌다가 3–6초 뒤 일어나 가까운 보도로 돌아가 다시 걷는다. 부딪힌 차는 긴급제동(연산 점유).
- 수동 운전은 ADAS 자동 긴급제동이 기본으로 켜져 있어 대부분 멈춘다. 차량 설정의 "수동 운전 시 ADAS 자동 긴급제동"을 끄면 그대로 부딪힌다.

## 직접 운전 (선택 차량 1인칭)

맵 위 **🕹 운전 켜기**를 누르면 선택 차량이 1인칭 시점으로 바뀌고 키보드로 운전한다. 끄면(또는 Esc, 창을 닫아 입력이 2초 끊기면) 그 차는 자기 경로에서 가장 가까운(방향이 맞는) 차로 지점으로 옮겨 자동 운전을 이어간다.

| 키 | 동작 |
|---|---|
| W / ↑ | 가속 |
| S / ↓ | 제동 (서서히 세짐) |
| A D / ← → | 조향 (속도가 빠를수록 덜 꺾임) |
| Space | 급제동 |
| R | 전진·후진 기어 (멈춘 상태에서) |
| P | 주차장 칸 근처에서 멈춰 있으면 주차, 주차 중이면 출발 |
| F | 1인칭 켜고 끄기 · 드래그 = 둘러보기 · 더블클릭 = 정면 |

- 브라우저 → `POST /api/drive`(0.1초마다) → `RUN_DIR/drive.json` → world.py가 매 틱 읽어 자전거 모델로 움직인다. 운전 중인 차는 응답으로 위치를 바로 받아 그린다.
- 다른 차·건물·맵 경계와는 겹치지 않는다. 도로 밖은 25 km/h 제한. 자동 주행 차들은 운전 중인 차도 앞차로 보고 멈춘다.
- **유스케이스는 위치·속도대로 그대로 일어난다**: 셀 범위·핸드오버·터널·음영·Wi-Fi·권역 경계·혼잡·강우가 자동 주행과 똑같이 계산된다.
- 정지 거리 안에 앞차·보행자·건물이 있으면 **ADAS 자동 긴급제동**이 운전자 입력보다 우선해 멈추고, 30 km/h 넘게 달리다 Space를 누르면 **운전자 급제동** → 둘 다 연산 점유(4-5 학습 지연, 확률적으로 1-4 FL 종료)로 이어진다. 신호 위반(적색 진입)은 사건으로 남는다.
- 주차: 집·직장·차고지 = 시동 꺼짐(1-5 등), 충전소 = 충전(3-1), 서비스센터 = 정비 대기. 운전을 끄면 30초 뒤 자동으로 출발.
- 1인칭에서는 그 차에 일어난 사건(유스케이스·운전 사건)이 계기판 위에 잠깐 뜬다.

| **설정** (오른쪽 끝, ▶ 띠로 접기) · **차량** | 차량 종류(신형/구형 EV), 일정, 연산 배수, 긴급제동 민감도·연산 점유 시간·FL 종료 확률, 참여 조건, 배터리 크기, 데이터 배수, 보관 후 전송, 오류 값 |
| **전체 설정** | 학습 방식·시드·SASAFL 값, 통신(업데이트 크기 포함)·에너지·하루 시계·주행 환경·서버. "34개 전부 보이기" 프리셋 |
| **저장·맵** | 현재 상태 저장/불러오기, **맵 7종 카드(34/34)**, 맵 JSON 올리기·내려받기, 유스케이스별 맵 위치 표 |

바닥 링·지붕 표시등·이름표 색 = 연합학습 상태(회색 = 주차·시동 꺼짐), 멀리서는 같은 색 동그라미로 보인다. 아주 먼 장소·도로 이름표는 감춘다.

## 학습 방식 (같은 하네스, 기능만 켜고 끔 → ablation)

| 방식 | 적응형 quota | staleness 감쇄 | 학습 중 교체·epoch 축소 | quota |
|---|---|---|---|---|
| SASAFL (현재 코드 + optimizer 수정) | O | O | O | C·K부터 |
| SASAFL 원저자 코드 | X | O | O | C·K |
| BSA (SemiAsync) | X | O | X | C·K |
| FedAsync | X | O | X | 1 |
| 동기식 | X | X | X | K |

시드가 같으면 데이터 분할·주행·차량별 무작위 사건이 같게 시작한다 (학습 시간에 따른 순서 차이는 남는다).

## 패턴을 만드는 방법

| 패턴 | 맵·설정 | 구현 / SASAFL이 보는 모습 |
|---|---|---|
| 1 값을 전달받지 못함 | 계산 중단, OTA, 학습 중 방전, 긴급제동 선점, 주차(시동 꺼짐) | 학습 중단, 보내지 않음. **프로세스는 살려 두고 수신은 계속**(원본은 한 대라도 수신을 멈추면 서버 `dist.send`가 막힌다) |
| 2 전송 중 끊김 | 범위 이탈·핸드오버, 도플러, 패킷 오류, 권역 경계, 터널, 전송 중 방전 | 전송 시간(업데이트 크기/대역폭)을 n등분해 기다리며 연결 확인, 끊기면 보내지 않음. 패킷 오류·도플러는 재전송으로 복구되면 4-3으로 이어짐. 실제 `dist.send`는 원본처럼 한 번 → 조각 개념이 없어 서버에선 패턴 1처럼 보인다 |
| 3 해당 라운드 미참여 | 에너지 기준, 새 데이터 없음(충전 중·정비 대기), Wi-Fi 조건 | 학습을 시작하지 않고, 조건이 풀리면 **마지막으로 받은 최신 글로벌 모델로 복귀** |
| 4 늦게 도착 | 구형 EV, 기지국 혼잡, 재전송, 대역폭·강우, 긴급제동 연산 점유, 데이터 양(택시), TDMA, 새 모델 수신 실패 | 지연 / 이전 버전으로 학습 → staleness |
| 5 모아서 한꺼번에 | 보관 후 전송 + 터널·음영·셀 가장자리, 서버 장애 | 보관했다가 연속 `dist.send`. 원본 서버는 차량당 버퍼 1칸이라 덮어쓰고 비중을 두 번 나눈다 |
| 6 오류 값 지속 전송 | 업데이트 증폭, 센서 고장 라벨, 학습률 | 매 업데이트마다 오염된 값 전송 (너무 세면 loss NaN → 서버 `int(NaN)` 종료) |
| 7 빠른 클라이언트 편중 | 신형/구형, 주행 중 통신 품질, 하루 시계 | 최근 W라운드 집계 구성을 감시: 신형 EV 비중(7-1), 통신 품질 상위 절반 비중(7-2), 시간대별 차량 종류 구성(7-3) |
| 8 서버·글로벌 모델 문제 | 서버 장애 버튼, quota > 보낼 수 있는 차량(밤), 새 모델 연속 거부 | 일시 중단 후 복구(차량은 보관), 무한 대기 감지, lag ≥ τ 강제 갱신 기록 |

## 원본과 다르게 둔 것
1. busy-wait 두 곳에 짧은 sleep (CPU 절약, 동작 동일)
2. **복귀 허용**(전체 설정): 원본은 한 번 빠진 차량이 다시 선택되지 않는다. 끄면 원본처럼 영구 제외
3. 학습 중 글로벌 모델 교체 뒤 optimizer를 다시 만든다 (main `8f430a7`의 버그 수정과 같음)

## 주의
- 실제 학습을 하므로 CPU를 쓴다 (차량 8대 ≈ 프로세스 9개, 1스레드씩). 같은 노드에서 다른 실험이 돌면 그 실험이 느려진다.
- 주행 시간·거리·속도는 실제 단위(1배)이고 하루 시계만 빠르게 간다 (기본 30분 = 24시간). 그래서 출퇴근 길이 시계로는 2–3시간 걸린다.
- 메모리는 실행 시간에 비례해 늘지 않도록 기록·화면 목록에 상한을 두었다 (실행 기록 파일은 디스크에 쌓인다).
